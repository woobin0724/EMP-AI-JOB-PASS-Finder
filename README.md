# AI Job Pass Finder

> "학교에서 시장으로" — 마이스터의 등용문을 여는 AI 맞춤형 취업 파트너

**전북기계공업고등학교 팀 E.M.P (Employment Meister Partner)**
김우빈(팀장·개발·기획) · 김정수(문서·디자인) · 오상명(영상·개발) · 이건희(백엔드·데이터)

제4회 NAVER OGQ마켓 AI Competition 출품작

## 1. 무엇을 해결하나 — "실력은 마이스터, 정보는 미스매치"

마이스터고 학생은 실무 역량이 있어도, 자신의 **5등급 성취평가제 내신**과 **전공 자격증**이
어느 기업에 통하는지 스스로 판단하기 어렵습니다.

AI Job Pass Finder 는 내신과 자격증을 **목표 기업별 100점 만점 '합격 지수'**로 바꿔 보여 주고,
그 점수를 바탕으로 **기업 탐색 → 채용 대비 → 자소서 작성**까지 한 앱에서 이어지게 합니다.
선생님은 반 코드로 학생들을 모아 진행 상황을 한 화면에서 봅니다.

## 2. 화면과 기능

화면 15개 — 사용자 화면 13개 + 팀 관리자 화면 2개 (`app.py` 의 `ROUTES`).

| 랜딩 | 서비스 소개 → '시작하기' |

| 역할 선택 | 학생 / 선생님 |

| 허브 | 4대 기능 중 하나 선택 |
| ① 스펙 진단 | 학과·내신·자격증·강점·목표 기업 입력 → **입력 즉시 100점 점수**(기업 유형별 배점), 항목별 막대 + **"왜 이 점수인지"** 한 줄씩, **점수 올리기 시뮬레이션**(이 자격증을 따면 +몇 점 · 내신이 오르면 안정권에 들어오는 기업), 점수 설명, 다음 행동 제안 |

| ④ 자소서 | 자소서 초안 생성(문체·분량·다시 생성) · **무료 AI 에 붙여넣을 요청문 복사** · 직접 쓴 초안 첨삭 + **문장별 인재상 연결** · **텍스트 모의 면접**(연습 질문 5개 → 인재상 기준 피드백, 무료 계정은 규칙 점검 + 요청문 복사) |
| 로드맵 | 만든 기능과 '아직 만들지 않은 기능 + 이유' |
| 마이페이지 | 이어하기 코드, 점수 기록, 로드맵, 찜·열람 기록, 반 정보, 요금제, 개인정보 처리방침, **내 기록 지우기**(학생) |
| 우리 반 (선생님) | 반 평균 점수, 학생별 목표 기업·진행 단계·점수, 관심이 필요한 학생, **이 기업에 맞는 학생 목록**, **반 현황 엑셀(CSV) 내려받기** |
| 개인정보 처리방침 | 무엇을·어디에 저장하고 언제 지우는지, 밖으로 보내는 것 (로그인 없이 볼 수 있음) |

## 3. 합격 지수 — 계산 방식 (`core/matching.py`)

**AI 를 쓰지 않는 파이썬 계산**이라 입력하는 즉시 바뀌고 비용이 들지 않습니다.

```
합격 지수(100) = 내신 성취도 + 자격증 가산점 + 전공 적합성 + 인재상 일치도   (각 항목 = 비율 × 배점)

- 내신   : 배점 × (5.0 − 등급) ÷ 4.0             1.0등급 = 만점, 5.0등급 = 0점
- 자격증 : 기업 요구 자격증마다 정확히 보유 100% · 유사 자격증 70% · 미보유 0% → 평균 × 배점
           (요구 자격증이 없으면 보유 1개당 배점의 1/5, 최대 배점)
- 적합성 : 학과 계열 = 기업 계열 100% · 다르면 25% · 기업 미선택 50%
- 인재상 : 내 강점 키워드 중 기업 인재상과 겹치는 비율 × 배점
```

| 기업 유형 | 내신 | 자격증 | 전공 | 인재상 |
|---|---|---|---|---|
| 일반 진단(기업 미선택) · 중견기업 | 30 | 40 | 20 | 10 |
| 공기업 | 25 | 45 | 20 | 10 |
| 대기업 | 30 | 35 | 20 | 15 |
| 중소·강소기업·스타트업 | 25 | 40 | 25 | 10 |

배점의 근거와 한계(팀 가설, ±5점만 조정)는 `docs/scoring.md`. 일반 진단·중견기업 점수는 예전과 같습니다.
시뮬레이션(`core/score_simulation.py`)은 같은 계산식을 입력 하나만 바꿔 다시 돌린 값입니다.

- 기업 탐색의 정렬·추천과 스토리 카드의 '내 매칭 점수'도 같은 계산을 씁니다 (`core/company_filter.py`).
- 추천: 매칭 상위 4곳, 40점 미만은 추천하지 않습니다.
- 점수 구간 반응: 80점 이상 '합격 안정권' / 50~79 '분발 필요' / 50 미만 '보완 시급'.

## 4. 데이터와 출처

**스크래핑은 하지 않습니다.** 데이터는 ① 공식 API 또는 ② 팀이 직접 조사해 출처와 함께 입력한 데이터만 씁니다.
예전에 잡알리오·강소기업 포털을 스크래핑하던 코드는 삭제했습니다(커밋 `762172d`).

| 데이터 | 공식 API (키가 있을 때) | 키가 없거나 실패하면 |
|---|---|---|
| 자격증 | 공공데이터포털 Q-Net (`services/qnet_api.py`) — **공식 활용가이드 기준 검증 전** | `data/certifications.py` 45종 |
| 채용공고 | 고용24 Open API (`services/worknet_api.py`) — **미검증** | `data/companies.py` 34건 |
| 공기업 공고 | 설정 자리만 있음 (`services/api_registry.py`) | 가상 공공기관 예시 10건 (BACKUP) |
| 강소기업 공고 | 설정 자리만 있음 | 가상 강소기업 예시 10건 (BACKUP) |
| 실제 기업 정보 | (공식 홈페이지·채용공고·공공데이터에서 팀이 확인) | 출처·수집일 필수, 별점·리뷰 금지 (`docs/data_schema.md`) |

- 모든 외부 호출은 `services/fallback.py` 의 `safe_call()` 로 감싸 실패해도 화면이 멈추지 않습니다.
  화면에는 **LIVE API / BACKUP DATA / CURATED** 배지로 출처를 표시합니다. 강소기업 예시 공고는 가상 데이터라
  BACKUP 으로 표시합니다(예전에는 CURATED 로 잘못 표시했습니다).
- Q-Net·고용24 연동은 '공식 활용가이드 기준 검증 전, 키 미설정 시 백업 데이터로 동작'합니다. 활용가이드로 규격을 확인한 뒤
  `services/api_registry.py` 를 채워야 실제 연동이 됩니다.
- 팀이 넣는 실제 기업 정보는 **출처 URL · 출처 유형 · 조사자 · 수집일이 없으면 저장되지 않고**, 별점·리뷰·면접 후기·연봉처럼
  확인할 수 없는 항목은 입력란 자체가 없습니다 (`services/curated.py`, 검사 도구 `scripts/update_company_data.py`).
  스키마와 갱신 절차는 [`docs/data_schema.md`](docs/data_schema.md).

### 예시(모의) 데이터 안내
- 기업 분석 카드 20곳(`data/company_showcase.py`)의 **기업명은 모두 가상**이고, 별점·복지·인재상·
  선배 리뷰·면접 질문·합격자 평균 스펙은 팀이 만든 **예시 데이터**입니다. 화면에도 "예시 데이터" 안내를 띄웁니다.
  (예전에는 일부 실제 기업명을 썼으나 실제 정보로 오해될 수 있어 가상 이름으로 바꿨습니다 — 커밋 `22d2c83`)
- 채용공고 백업 34건·강소기업 10건의 기업명도 가상입니다.
- 공기업 백업 10건(`data/companies.py` 의 `BACKUP_PUBLIC_COMPANIES`)도 **가상 기관명**입니다. 예전에는 실제 공공기관명에
  팀이 만든 채용 분야·가산점 설명을 붙였는데, 실제 기관에 사실이 아닌 정보를 붙이는 셈이라 바꿨습니다(big-patch 1단계).
  확인할 수 없는 채용 조언(`ai_tip`)도 모두 비웠습니다.
- 근무지·근무 조건은 확인된 값이 없어 비워 두었습니다(지어내지 않음).

## 5. Claude API 활용과 비용 방어

| 기능 | 파일 | 모델 등급 (`services/ai_models.py`) | AI 가 없을 때 |
|---|---|---|---|
| 자소서 초안 생성 | `services/coverletter.py`, `services/llm.py` | 초안 등급(저가) | 문장 풀 템플릿 생성기 |
| 자소서 최종 첨삭 | `services/review.py` | **상위 등급** | 규칙 점검(분량·상투어·문장 길이 등) + 문장별 인재상 연결 |
| 모의 면접 피드백 | `services/interview.py` | 초안 등급(저가) | 규칙 점검(숫자·행동·결과·인재상) + 요청문 복사 |
| 점수 설명 | `services/score_explain.py` | 초안 등급(저가) | 규칙 기반 설명 |
| 기업 스토리 카드 1~4 | `services/story_cards.py` | 상위 등급 (기업별 24시간 + 파일 캐시) | 원본 데이터로 만든 기본 카드 |

**비용 방어**
1. **점수 계산은 AI 에 맡기지 않습니다.** AI 는 이미 계산된 점수를 '설명'만 합니다.
2. **캐싱**: 같은 입력은 다시 호출하지 않습니다(`st.cache_data`). 스토리 카드는 `data/story_cache.json` 에도 저장해
   앱을 다시 켜도 재호출하지 않습니다.
3. **프리미엄 게이트** (`services/premium.py`): API 키가 있어도 `PREMIUM_USER_IDS`(소셜 로그인 계정) 또는
   `DEMO_USER_IDS`(시연용) 계정만 Claude 를 호출합니다. 두 목록이 비어 있으면 **호출 0회**입니다.
   결제 연동은 없습니다(화면에 '결제 연동 준비 중'으로 표시).
4. **무료 대안**: 같은 지시문으로 만든 요청문을 복사해 학생이 무료 AI 채팅에 붙여넣을 수 있습니다.
5. **키 격리**: API 키는 `st.secrets` 에서만 읽고 코드에 쓰지 않습니다. 실패·거절 시 규칙 기반으로 전환하고 이유를 화면에 표시합니다.
6. 프롬프트에 "학생·원본 데이터에 없는 사실을 지어내지 말 것"을 명시했습니다.
7. **하루 한도** (`services/ai_quota.py`): 학생 1명당 하루 자소서·첨삭·면접 합계 10회 + 점수 설명 10회. 실제 호출만 세고(캐시 제외), 넘으면 규칙 기반으로 계속 씁니다.
8. **모델 나누기**: 초안은 저가 모델, 최종 첨삭만 상위 모델. secrets(`AI_MODEL_DRAFT`·`AI_MODEL_FINAL`)로 바꿀 수 있습니다.

학생 1명 한 달 예상 비용(`docs/cost.md`): 무료 학생 **0원**, 프리미엄 보통 사용 **약 1,800원(패치 전 대비 −51%)**, 최악 상한 약 29,000원.
수익 모델(학생 무료 · 학교 취업지원실 구독 · 교육청 단위 도입)은 `docs/bm.md`.

## 7. 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

API 키를 하나도 넣지 않아도 모든 화면이 동작합니다(백업 데이터 · 규칙 기반 결과).

### 설정 (`.streamlit/secrets.toml`, 배포 시 Streamlit Cloud 의 Secrets) — 전부 선택

예시는 `secrets_example.toml` 에 있습니다. **secrets 파일은 절대 커밋하지 마세요.**

| 항목 | 용도 |
|---|---|
| `CLAUDE_API_KEY` | Claude API 키 (프리미엄·데모 계정만 사용) |
| `AI_DAILY_LIMIT` · `AI_DAILY_LIMIT_EXPLAIN` | 학생 1명당 하루 AI 한도 (기본 10 · 10) |
| `AI_MODEL_DRAFT` · `AI_MODEL_FINAL` | 초안 등급 · 최종 첨삭 등급 모델 이름 (비우면 `services/ai_models.py` 기본값) |
| `PREMIUM_USER_IDS` | AI 기능을 쓸 소셜 로그인 계정 목록 |
| `DEMO_USER_IDS` | 시연용 계정(게스트 가능) — 시연 후 지울 것 |

## 11. 알려진 한계

- Q-Net·고용24 실제 연동은 키와 규격 확인 전이라 현재는 백업 데이터로 동작합니다.
- 공기업·강소기업 공고는 공식 API 미연동(이름까지 가상인 예시 공고).
- 팀 큐레이션 기업 데이터는 아직 0건입니다.
- 프리미엄 결제는 구현되어 있지 않습니다(운영자가 계정을 지정).
- 유형별 배점·비용 추정·BM 가격은 팀 가설입니다(`docs/scoring.md` · `cost.md` · `bm.md` 의 [팀 확인 필요]).
- 모의 면접 규칙 점검과 문장↔인재상 연결은 단어 기준 추정이라 글의 뜻을 평가하지 않습니다.
- 소셜 로그인은 각 플랫폼 키를 등록해야 켜집니다.
- Supabase 를 연결하지 않으면 재배포 때 사용자·기록이 사라집니다.
