# API 비용 방어와 학생 1명당 한 달 예상 비용

> big-patch 4단계. 코드: `services/ai_models.py`(모델 등급), `services/ai_quota.py`(하루 한도),
> `services/llm.py` · `review.py` · `score_explain.py` · `interview.py`(캐시), 테스트 `tests/test_cost_metrics.py`.

## 1. 비용 방어 4겹

| 겹 | 내용 | 효과 |
|---|---|---|
| ① 무료가 기본 | AI 호출 = 키 있음 **그리고** 프리미엄(또는 운영팀이 지정한 시연) 계정. 그 외 학생은 규칙 기반 결과 + "요청문 복사" | 무료 학생 1명당 비용 **0원** |
| ② 같은 요청 캐시 | 같은 입력이면 1시간 동안 다시 부르지 않는다(`st.cache_data`). 스토리 카드는 기업별 24시간 + 파일 캐시 | 버튼 반복 클릭 · 새로고침 비용 0 |
| ③ 하루 한도 | 학생 1명당 하루 **자소서·첨삭·모의 면접 합계 10회**, **점수 설명 10회**. 한도를 넘으면 그날은 규칙 기반으로 계속 쓸 수 있다. 실제 호출만 센다(캐시 적중 제외) | 학생 1명의 최대 비용이 정해진다 |
| ④ 모델 나누기 | 초안(자소서 초안 · 점수 설명 · 면접 피드백)은 **초안 등급** 모델, 제출 직전 **최종 첨삭만 상위 등급** 모델 | 자주 쓰는 기능의 단가를 낮춘다 |

운영자가 코드 수정 없이 바꿀 수 있는 값(st.secrets): `AI_DAILY_LIMIT`, `AI_DAILY_LIMIT_EXPLAIN`, `AI_MODEL_DRAFT`, `AI_MODEL_FINAL`.
한도 횟수는 사용 기록 문서(`usage`)에 해시 ID로 오늘 날짜만 남긴다(Supabase 사용 시 같은 `app_state` 테이블, 스키마 변경 없음).

## 2. 가정

| 항목 | 값 | 근거 |
|---|---|---|
| 초안 등급 모델 단가 | 입력 $2 / 출력 $10 (100만 토큰당) | Anthropic 공개 가격표(2026-10 기준) |
| 상위 등급 모델 단가 | 입력 $4 / 출력 $20 | 같음 |
| 패치 전 모델 단가 (모든 기능 같은 모델) | 입력 $5 / 출력 $25 | 같음 |
| 환율 | 1달러 = 1,400원 | 계산 편의 [가정] |
| 호출 1회 토큰 (출력에는 추론 토큰 포함) | 자소서 초안 입력 2,000 · 출력 3,000 / 최종 첨삭 2,500 · 2,500 / 면접 피드백 800 · 1,200 / 점수 설명 600 · 800 | 프롬프트 길이와 출력 형식으로 잡은 추정치. 실제 사용량(`response.usage`)으로 확인해야 한다 [팀 확인 필요] |
| 보통 학생의 사용 | 한 달 8일 접속, 접속한 날마다 자소서 초안 1 · 최종 첨삭 1 · 면접 피드백 3 · 점수 설명 3 | 팀 가정. 취업 준비 시기(3학년 1학기) 기준 [가정] |
| 캐시 적중 | 0%로 계산 | 보수적으로 (실제로는 더 싸다) |

## 3. 계산표

| 기능 | 모델 등급 | 1회 비용 | 패치 전 1회 비용 |
|---|---|---|---|
| 자소서 초안 | 초안 | $0.034 | $0.085 |
| 최종 첨삭 | 상위 | $0.060 | $0.075 |
| 모의 면접 피드백 | 초안 | $0.0136 | $0.034 (같은 모델이었다면) |
| 점수 설명 | 초안 | $0.0092 | $0.023 |

| 학생 1명 · 한 달 | 패치 전 | 패치 후 |
|---|---|---|
| 무료 학생 (기본) | 0원 | **0원** |
| 프리미엄 · 보통 사용 (8일) | $2.65 ≈ 3,700원 | **$1.30 ≈ 1,800원 (−51%)** |
| 프리미엄 · 최악 (30일 내내 한도까지, 쓰기 10회를 모두 최종 첨삭으로) | 상한 없음 | **$20.76 ≈ 29,000원 (상한)** |

계산: 보통 사용 하루 = 0.034 + 0.060 + 3×0.0136 + 3×0.0092 = $0.162, × 8일 = $1.30.
최악 하루 = 10×0.060 + 10×0.0092 = $0.692, × 30일 = $20.76.

## 4. 학교 단위로 보면
- 한 반 30명이 모두 프리미엄으로 보통 사용: 30 × $1.30 = **$39 ≈ 5.5만 원/월**. 최악이라도 30 × $20.76 ≈ 87만 원이 상한이다.
- 무료 학생은 몇 명이 들어와도 0원이라, 대회 시연이나 QR 접속으로 사람이 몰려도 비용이 늘지 않는다.
- 이 숫자가 `docs/bm.md` 의 학교 구독 가격을 정하는 바닥값이다.
