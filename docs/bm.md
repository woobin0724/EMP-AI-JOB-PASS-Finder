# 수익 모델(BM) — 학생 무료 · 학교 취업지원실 구독 · 교육청 단위 도입

> big-patch 5단계. 가격은 **팀 가설**이며 실제 학교·교육청과 협의한 값이 아니다 [팀 확인 필요].
> 원가는 `docs/cost.md`, 지표는 관리자 '사용 통계' 화면(`services/usage_log.summarize`)에서 나온다.

## 1. 한눈에

| 대상 | 내는 사람 | 받는 것 | 가격 (가설) |
|---|---|---|---|
| 학생 | 없음 | 스펙 진단·시뮬레이션·기업 탐색·가이드·로드맵·자소서 템플릿·규칙 기반 첨삭·모의 면접(규칙 점검)·요청문 복사 | **무료** |
| 학교 취업지원실 | 학교(취업지원 예산) | 선생님 반 화면(우선 지도 학생 · 기업별 맞는 학생 · CSV), 소속 학생 AI 기능(자소서 작성·최종 첨삭·면접 피드백·점수 설명, 하루 한도) | 학생 1명당 월 3,000원, 최소 30명 |
| 교육청 | 교육청(관내 일괄) | 관내 마이스터고·특성화고 전체 학교 구독 + 학교별 지표 보고서 + 실제 기업 데이터 공동 검증 | 학교 구독가에서 30% 할인한 일괄 계약 |

## 2. 왜 학생은 무료인가
- 학생 화면의 핵심 기능(점수 계산·시뮬레이션·탐색·규칙 점검)은 **AI 를 부르지 않는 로컬 연산**이라 학생이 늘어도 비용이 0원이다(`docs/cost.md` §1).
- 학생이 무료로 써야 선생님 화면에 데이터가 쌓이고, 그 데이터가 학교가 돈을 낼 이유가 된다.
- 무료 학생도 "요청문 복사"로 무료 AI 서비스를 쓸 수 있어 AI 경험 자체가 막히지 않는다.

## 3. 학교 구독의 근거 (원가와 마진)

| 항목 | 값 |
|---|---|
| AI 원가 · 보통 사용 학생 1명/월 | 약 1,800원 ($1.30) |
| 구독가 · 학생 1명/월 | 3,000원 (가설) |
| 학생 1명당 매출총이익 | 약 1,200원 (40%) |
| 최악 원가(한도까지 매일) | 약 29,000원 — 하루 한도를 학교 플랜에서 낮추면(`AI_DAILY_LIMIT`) 상한도 비례해 낮아진다 |
| 저장소·서버 | Streamlit Community Cloud + Supabase 무료 구간에서 시작 가능 [팀 확인 필요] |

- 학교가 사는 것은 AI 가 아니라 **선생님 시간**이다: "누구를 먼저 도울지"(우선 지도 학생), "이 기업에 누구를 추천할지"(기업별 맞는 학생), 반 현황 CSV 로 취업 상담 기록을 바로 만든다.
- 취업 시즌(3학년 1학기)에 사용이 몰리므로 연 계약보다 **학기 계약**이 학교 예산 흐름에 맞는다는 것이 팀 가설이다 [팀 확인 필요].

## 4. 교육청 단위 도입
- 관내 학교를 한 번에 열면 학교마다 영업할 필요가 없고, 학교별 지표(가입 수 · 재방문 비율 · 스펙 진단 완료율 · 자소서·면접 사용 수)를 해시 ID 기반 통계로 보고할 수 있다. 개인 식별 정보는 보고서에 들어가지 않는다.
- 실제 기업 데이터(`docs/data_schema.md`)를 교육청 취업지원센터와 함께 공식 채용공고 기준으로 검증하면, 데이터 신뢰성이 이 서비스의 진입 장벽이 된다.

## 5. 지금 구현된 것과 아닌 것

| 구분 | 상태 |
|---|---|
| 학생 무료 기능 전체 | 구현 |
| 선생님 반 화면 · 기업별 맞는 학생 · CSV | 구현 |
| 하루 AI 한도 · 모델 등급 · 캐시 | 구현 |
| 사용 지표(관리자 통계) | 구현 — 운영 서버에 `APP_ENV = "production"` 필요 |
| 결제 | **미구현.** 프리미엄은 운영자가 secrets 의 `PREMIUM_USER_IDS` 로 지정한다. 결제 정보를 받는 화면은 만들지 않았다 |
| 학교 단위 프리미엄 일괄 지정(반 코드 → 학생 전체) | 미구현. 다음 단계 후보 |

## 6. 이 모델이 맞는지 확인할 숫자
관리자 '사용 통계'의 핵심 지표로 시범 학교에서 확인한다.
- 재방문 비율 — 학생이 다시 오는가 (무료 모델의 전제)
- 스펙 진단 완료율 — 첫 화면에서 가치를 느끼는가
- 자소서·모의 면접 사용 학생 수 — 유료 기능의 수요
- 선생님 1명당 반 학생 수 · CSV 내려받기 — 학교 구독의 수요 [CSV 내려받기 횟수는 아직 기록하지 않음]
